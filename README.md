# My Store

An e-commerce store where the owner manages products from their phone — no developer, no spreadsheet, no monthly fees.

## What it does

- **For the owner:** Open the admin app, upload a photo, type the price and details, and the product appears on the store instantly. No coding, no calling a developer.
- **For customers:** Browse products, add to cart, place an order — the order goes straight to the owner's WhatsApp.

## How it works

- **Backend:** Google Sheets (product data) + Google Apps Script (logic)
- **Images:** Cloudinary
- **Frontend:** HTML, CSS, JavaScript
- **Orders:** WhatsApp integration
- **Hosting:** Netlify

## Built with

AI-assisted development (DeepSeek, ChatGPT). Built entirely from a mobile phone.
